# Obsidian 知识库

这是一个使用 Obsidian 管理的中文知识库，内容包括：

- Obsidian 配置与使用
- Codex / AI 教程研究
- 抖音短视频选题、脚本、分镜与竞品拆解
- 项目、领域、资源、归档和模板

## 使用方法

1. 克隆或下载本仓库。
2. 使用 Obsidian 打开仓库根目录。
3. 从 `知识库主页.md` 开始浏览。
4. 在 Obsidian 中打开“关系图谱”查看笔记关联。

## 目录

- `00-收件箱/`：待整理内容
- `10-项目/`：正在推进的项目
- `20-领域/`：长期维护领域
- `30-资源/`：主题资料与研究
- `40-归档/`：已归档内容
- `90-模板/`：笔记模板

## 同步说明

本仓库不上传 Claudian 会话、迁移备份、Obsidian 工作区状态及本地插件程序。大型视频文件建议使用 Git LFS 或独立网盘保存。

> 请勿在笔记中提交 API Key、访问令牌、密码或其他敏感信息。
