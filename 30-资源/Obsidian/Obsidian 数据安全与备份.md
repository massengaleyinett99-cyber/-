# Obsidian 数据安全与备份

## 三个不同概念

- **同步**：让多设备保持一致；误删也可能被同步。
- **File Recovery**：提供短期本地快照，不是完整备份。
- **备份**：独立保存、可回滚，并能在原设备损坏后恢复。

## 最低方案

1. 保留 File Recovery，定期检查快照是否可用。
2. 将整个 Vault 备份到另一块物理磁盘或可靠云端。
3. 至少保留一个带历史版本的副本。
4. 定期执行恢复测试，而不只确认“备份任务成功”。
5. API Key、工作机密等敏感数据避免写入公开笔记或截图。

> [!danger]
> 2026-08-08 检查时，Vault 所在的 C 盘空间已接近耗尽。应优先清理空间并完成独立备份。
