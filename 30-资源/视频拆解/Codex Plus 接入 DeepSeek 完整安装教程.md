# Codex Plus 接入 DeepSeek 完整安装教程｜内容分解

## 一句话总结

视频演示了在 Windows 上通过 Codex Plus 以纯 API 模式接入 DeepSeek、启用 Codex 原生插件和 Computer Use，并用一次实测说明高推理速度下 Computer Use 的成本可能非常高。

## 安装操作清单

1. 打开 Codex Plus 管理工具。
2. 进入“供应商配置”，点击“添加供应商”。
3. 从预设模板创建 DeepSeek V4。
4. 没有 GPT 账号时选择“纯 API”模式。
5. 填入在 DeepSeek 官网充值后获取的 API Key。
6. 接口模式选择 Chat Completions。
7. 保存、启用并执行连接测试。
8. 重启 Codex Plus，通过它打开 Codex。
9. 在设置中将语言切换为 Chinese。
10. 检查插件；若 Computer Use 未出现，先重启。
11. 连接 Computer Use，根据风险谨慎配置权限与推理速度。

## 核心观点

- Codex Plus 的主要价值是让第三方模型接入时仍能使用 Codex 的原生插件能力。
- Computer Use 的速度与推理档位有关，但速度越高可能意味着更快的余额消耗。
- 视频实测中，约 10 元余额在“超高”推理模式下很快耗尽；这是个案，不应直接视为固定计费标准。
- 对重复性工作，应优先比较脚本、RPA 或其他自动化方案的成本。

## 风险提醒

- API Key 属于敏感凭据，不应在视频、截图或公开笔记中暴露。
- Computer Use 获得较高权限后能够操作本机；不建议在存有重要资料的环境中直接开放全部权限。
- 模型名称、价格和界面可能随版本变化，实际使用前应核对服务商当前说明。
