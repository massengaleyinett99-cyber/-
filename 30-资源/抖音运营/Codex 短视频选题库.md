## 主选题定义

**一句话承诺：** 60–75 秒内，用真实控制画面证明 Codex 接国产模型后是否保留 Computer Use，并公开一次任务的实际成本和限制。

**差异化：** 不再做普通“保姆级安装”，而是把“功能证明、成本、失败边界”放在同一条视频里。

**必须拍到的证据：**

- 当前软件版本和 Windows 环境
- 插件／工具列表
- Computer Use 成功控制画面
- API 余额前后对比或可核验账单
- 一次失败或限制说明
