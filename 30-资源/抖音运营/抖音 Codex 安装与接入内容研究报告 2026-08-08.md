## 关键发现

### 1. 教程是“收藏型内容”

多个高表现样本的收藏接近或超过点赞。用户不是只看热闹，而是把视频当安装手册。视频必须提供清晰章节、可复现步骤和版本日期。

### 2. 短不必然胜过长

30 分钟的 S01 依然远高于多数短教程。决定表现的不是单纯时长，而是“这一条能不能解决完整问题”。短视频若要胜出，必须把承诺收窄到一个结果。

### 3. 最大内容缺口不是安装，而是安装后的失败

评论反复出现：登录、手机号、系统兼容、重启后模型消失、Computer Use 灰色、插件不可用、上下文报错、GitHub 下载失败。比起再做一条普通安装教程，更值得做“失败排查”和“功能是否被阉割”的实测。

### 4. 成本透明会形成信任差

“免费、无需魔法”很能吸引点击，但 DeepSeek API 并非无限免费，Computer Use 也可能快速消耗余额。主动说明计费和适用人群，能与泛化承诺形成差异。

### 5. 路径越多，用户越迷惑

CCSwitch、Codex++、模型 API、原生登录同时出现时，初学者很难判断每个工具的作用。成片应只讲一条主路径，并单独解释为什么需要中间层。

### 6. 真实结果必须前置

前 8 秒就展示插件列表、Computer Use 控制画面或最终成果；之后再讲步骤。不要先讲三分钟背景，最后才证明能用。

## 推荐内容方向

### 主选题

**不用 GPT 账号也能保留 Computer Use？实测 Codex 接 DeepSeek，并公开真实成本。**

- 差异点：功能是否保留＋真实操作证明＋成本警告
- 目标时长：60–75 秒
- 观众结果：知道能不能用、怎么验证、最容易踩什么坑
- 诚实边界：只陈述本机、本版本实测，不承诺所有环境都成功

### 备用选题

1. **装好 Codex 却没有 Computer Use？按这三步排查。**
2. **别再同时装两套工具：Codex 接国产模型的最短路径。**
3. **普通人到底该不该用 Codex？先算清一次任务的成本。**

## 建议的 65 秒结构

1. **0–3 秒：** “不用 GPT 账号也能保留 Computer Use？能，但这个坑可能让余额掉得比进度条快。”
2. **3–8 秒：** 先展示 Computer Use 成功控制电脑和插件列表。
3. **8–25 秒：** 三步配置，只保留必要操作。
4. **25–40 秒：** 输入真实任务，展示控制结果。
5. **40–52 秒：** 展示余额变化或失败画面，说明限制。
6. **52–65 秒：** 给出适用人群判断；引导查看“完整步骤＋避坑清单”。

## 风险边界

- 不使用“永久、完全免费、百分百成功”等承诺。
- 不展示 API 密钥、手机号、邮箱、订单或个人信息。
- 不把单次测试泛化成所有电脑都适用。
- 评论区若出现远程安装服务，不背书，不引导用户向陌生人交付账号或电脑权限。
- 发布前重新验证软件版本、插件名称、费用和界面。
